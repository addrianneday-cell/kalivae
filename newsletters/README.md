# Kalivae newsletter drafts

These are **editorial drafts**, not production emails. They are stored here so
they stay versioned alongside the articles they summarise.

## Status

- **Do not send.** No email-sending or list-import automation is wired up from
  this repository.
- **Consent-first.** The homepage quiz captures opt-in consent via Formspree.
  Business inquiries from `epoch.html` are a separate list and must not be
  mixed with the health newsletter audience.
- **Affiliate disclosure.** If a send ever includes a commission-eligible
  link, it must carry the same disclosure wording used at
  `/affiliate-disclosure.html`.

## Files

Each `*-newsletter.md` corresponds one-to-one with the matching article under
`/reviews/<slug>.html`. Article URLs in these drafts already point at the live
site.

## Workflow when you're ready to send

1. Human edit the draft for voice and current offers.
2. Paste into the sending platform (e.g. Mailchimp, Buttondown).
3. Keep a plain-text fallback and an unsubscribe link in every send.
4. Log the send date and audience segment somewhere auditable.
