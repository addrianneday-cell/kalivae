# Kalivae

Evidence-graded guides to longevity, skin health and supplements.

This repository holds the static site at **kalivae.com** (and the free GitHub Pages address until a custom domain is pointed at it).

- `index.html` — the homepage, including the personalized Longevity Protocol quiz.
- `img/` — brand photography used across the site.

## How to update

Tell Claude what to change on the site. Claude commits the change here, GitHub Pages picks it up, and the live site updates in about a minute.
